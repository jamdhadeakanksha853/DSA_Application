#ALGORITHM ORIGNAL_DOCUMENTATION
Step 1: Start the program.

Step 2: Create a Binary Search Tree node structure to store employee IDs.

Step 3: Insert employee IDs into the BST according to BST properties.

Step 4: Display the menu for inserting, searching, and displaying employee IDs.

Step 5: If insertion is selected, insert the new employee ID into the BST.

Step 6: If searching is selected, search for the given employee ID and display the result.

Step 7: If display is selected, perform inorder traversal to display employee IDs in sorted order.

Step 8: Repeat the operations until the user selects Exit.

Step 9: Stop the program.
