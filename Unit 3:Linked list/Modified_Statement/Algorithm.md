## Algorithm: Modified Polynomial Calculator

1. Start.
2. Create nodes containing coefficients, exponents, and pointers.
3. Implement Singly, Doubly, and Circular Linked Lists.
4. Create the first polynomial P(x) and the second polynomial Q(x).
5. Store polynomial terms in the respective linked lists.
6. Perform addition using the Singly Linked List.
7. Perform subtraction using the Doubly Linked List.
8. Perform multiplication using the Circular Linked List.
9. Combine terms having the same exponent.
10. Remove terms with zero coefficients.
11. Display the resultant polynomials.
12. Release the allocated memory.
13. Stop.
